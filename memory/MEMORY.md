# Sutando Memory Index

This file indexes all memory records. Each memory is stored in its own file with frontmatter (name, description, type).

## Memory Types

- **user**: Information about the user's role, goals, responsibilities, and knowledge
- **feedback**: Guidance on how to approach work (what to avoid and what to keep doing)
- **project**: Ongoing work, goals, initiatives, bugs, or incidents
- **reference**: Pointers to where information can be found in external systems
